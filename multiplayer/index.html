MULTIPLAYER

GitHub Pages can only host files, so the live game relay runs on one player's computer. That player is the host: their browser runs the game, everyone else joins. Players can use PC or phone, mixed.

Host (once, on a PC)

  1. Install Python 3.8+ and download server.py.
  2. Run 
    python server.py
    (listens on port 8080).
  3. Expose it to the internet, e.g. with ngrok or Cloudflare Tunnel: 
    ngrok http 8080
    and copy the address, e.g. abc123.ngrok-free.app.
  4. Open a game page below, paste the address in the Server box, press HOST A GAME, then START when everyone is in.

Join

Open a game page below, paste the same address in Server, pick a hero, press JOIN A GAME. Or use a link like .../multiplayer/mobile/?server=abc123.ngrok-free.app.

KEYBOARD & MOUSEPHONE / TOUCH

Friends on the same Wi-Fi can use the host's local address instead (e.g. 192.168.1.20:8080) without ngrok, but only from the plain http:// page that server.py itself serves, since browsers block insecure connections from https pages.
